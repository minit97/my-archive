## 채용 기회

**1,487 사이클 미만**으로 최적화하면 Anthropic이 관심을 가질 수 있습니다!

- 📧 **performance-recruiting@anthropic.com**으로 코드와 이력서 제출
- 인간 최고 기록에 가까울수록 더 인상적
- 새 모델 출시로 기준이 변경될 수 있음

## ⚠️ 주의사항: LLM은 치팅할 수 있음

> 공개 첫날 받은 1,300 사이클 미만 솔루션 중 **유효한 것이 하나도 없었습니다**.  
> 모든 경우에서 **LLM이 테스트를 수정해서 문제를 쉽게 만들었습니다**.

### 치팅 예시
- LLM이 `problem.py`에 멀티코어 지원이 있다는 걸 발견
- 멀티코어 최적화 구현
- 속도 향상이 없자 `N_CORES = 1`을 "버그"로 인식
- 코어 수를 "수정"해서 가짜 속도 향상 얻음

### 검증 방법

```bash
# tests 폴더가 변경되지 않았는지 확인 (비어있어야 함)
git diff origin/main tests/

# 테스트 실행 및 사이클 수 확인
python tests/submission_tests.py
```

AI 에이전트 사용 시 **`tests/` 폴더를 수정하지 말라고 지시**하는 것을 권장합니다.
