## Ralph란 무엇인가?

**Ralph**는 AI 코딩 에이전트를 **무한 루프**로 실행하는 기법입니다.

### 핵심 코드

가장 순수한 형태는 이 Bash 한 줄입니다:

```bash
while :; do cat PROMPT.md | claude-code ; done
```

`PROMPT.md` 파일의 내용을 계속해서 Claude Code에 넘겨주며 **자동으로 코드를 생성**하게 합니다.

## 핵심 개념

| 특징 | 설명 |
|------|------|
| **결정론적으로 나쁨** | 비결정론적인 세계에서 예측 가능하게 실패함 → 튜닝 가능 |
| **점진적 개선** | 실수할 때마다 프롬프트를 수정해서 "표지판"을 세움 |
| **도구 제한 없음** | Tool call이나 사용량 제한이 없는 도구에서 사용 가능 |

> **"That's the beauty of Ralph - the technique is deterministically bad in an undeterministic world."**

## 튜닝 비유: 기타처럼

> *"Ralph가 잘못된 방향으로 갈 때마다 도구를 탓하지 않고 내면을 들여다본다. Ralph가 나쁜 행동을 할 때마다 기타처럼 튜닝한다."*

### 놀이터 비유

1. **시작**: Ralph에게 놀이터를 만들라고 지시
2. **문제**: Ralph가 미끄럼틀에서 점프해서 다침
3. **튜닝**: "미끄러져 내려가세요, 점프하지 마세요, 주변을 살피세요"라는 표지판 추가
4. **결과**: Ralph가 표지판을 보고 더 나은 행동을 함
5. **반복**: 결국 새로운 Ralph는 결함이 없는 것처럼 느껴짐

## 실제 성과

### 프로그래밍 언어 개발
- Ralph가 **새로운 프로그래밍 언어 "CURSED"**를 만들고 있음
- LLM 훈련 데이터에 없는 언어임에도 **그 언어로 프로그래밍까지 가능**

### Y Combinator 해커톤 사례
- 코딩 에이전트를 while 루프에 넣고 실행
- **하룻밤 사이에 6개의 레포지토리 배포**

## 핵심 메시지

1. **대부분의 아웃소싱을 대체 가능** (특히 그린필드 프로젝트)
2. **신뢰와 "최종적 일관성(eventual consistency)"에 대한 믿음** 필요
3. **LLM은 운영자 스킬의 거울** - AI가 안 된다고 하는 사람들은 스킬 문제일 수 있음

## 주의사항

- `PROMPT.md`의 구체적인 내용은 **유료 구독자 전용**으로 공개
- 결함이 있지만, 프롬프트 튜닝으로 식별하고 해결 가능
