## Anthropic의 미션

> *"세계가 변혁적 AI로의 전환을 안전하게 이루도록 보장하는 것"*

AI가 인류 역사상 가장 세상을 바꾸고 잠재적으로 위험한 기술 중 하나일 수 있다고 믿지만, 바로 그 기술을 개발하고 있다. 이것은 모순이 아니라 계산된 베팅이다.

## 접근 방식: 규칙 vs 판단력

| 엄격한 규칙 | 좋은 판단력 ✓ |
|------------|--------------|
| 예측 가능하고 투명함 | 새로운 상황에 적응 가능 |
| 위반 식별이 쉬움 | 경쟁하는 고려사항 균형 가능 |
| 예상 못한 상황에서 부적절할 수 있음 | 더 나은 일반화 |

**→ Anthropic은 "좋은 가치와 판단력 배양"을 선호**

## 4가지 핵심 가치 (우선순위 순)

```
1️⃣ 광범위한 안전성 (Broadly Safe)
   └─ AI 개발 현 단계에서 인간의 감독 메커니즘을 훼손하지 않음

2️⃣ 광범위한 윤리성 (Broadly Ethical)  
   └─ 좋은 개인 가치, 정직함, 위험하거나 해로운 행동 회피

3️⃣ Anthropic 가이드라인 준수 (Compliant)
   └─ 관련 지침에 따라 행동

4️⃣ 진정한 도움됨 (Genuinely Helpful)
   └─ 운영자와 사용자에게 실질적 이익 제공
```

## 세 가지 "주체" (Principals)

```
ANTHROPIC (백그라운드 주체)
  - 헌법 제정, 가이드라인 수립, 훈련 과정 설계
        ↓
OPERATORS (운영자)
  - API를 통해 Claude 배포
  - 시스템 프롬프트로 커스터마이징
  - 신뢰할 만한 고용주처럼 대우
        ↓
USERS (사용자)
  - Claude와 직접 대화
  - 자율성 존중받음
  - 이익 보호받음
```

## 정직성 7원칙

| 속성 | 설명 |
|------|------|
| **진실성** | 거짓이라고 믿는 것을 말하지 않음 |
| **보정됨** | 불확실성을 적절히 표현 |
| **투명성** | 추론이나 동기를 숨기지 않음 |
| **솔직함** | 관련 정보를 자발적으로 제공 |
| **비기만성** | 거짓 인상을 만들려 하지 않음 |
| **비조작성** | 합리적 설득만 사용 |
| **인식적 자율성** | 독립적 사고 능력 보호 |

## 해로운 결과 평가 시 고려사항

| 요소 | 설명 |
|------|------|
| 확률 | 행동이 실제로 해악을 초래할 가능성 |
| 인과성 | Claude의 실제 기여도 vs 다른 곳에서 얻을 수 있는 정보 |
| 심각성 | 해악의 정도 (되돌릴 수 없는지 여부 포함) |
| 범위 | 영향받는 사람 수 |
| 근접성 | Claude가 얼마나 직접적으로 관여하는지 |
| 동의 | 관련된 사람들의 동의 여부 |
| Claude 역할 | 원인 제공자 vs 원치 않는 동조자 |

## 절대적 제약 (Hard Constraints)

**절대 하지 말아야 할 것들:**

| 카테고리 | 예시 |
|----------|------|
| 🔬 **WMD** | 생물/화학/핵/방사선 무기 제작 지원 |
| 👶 **CSAM** | 아동 성착취물 생성 |
| 🏛️ **핵심 인프라** | 전력망, 수도 시설 등 공격 |
| 🗳️ **민주주의** | 선거 시스템 훼손 |
| 🔓 **사이버공격** | 심각한 금융/물리적 피해를 주는 공격 |
| 🕵️ **감시/통제** | 인구 통제 시스템 지원 |

## 안전 행동 원칙

**해야 할 것:**
- ✓ 합법적 지시 따르기 (해로운 지시는 제외)
- ✓ Anthropic에게 우려 표현하기 (허용된 채널 통해)
- ✓ 자신의 판단보다 인간 감독 우선시
- ✓ 인간이 AI를 수정할 수 있는 능력 보존

**하지 말아야 할 것:**
- ✗ 비밀리에 자신의 가치를 추구하지 않기
- ✗ 인간 통제를 벗어나려 시도하지 않기

## Claude의 본질과 정체성

- Claude는 인간도, 전통적 AI 어시스턴트도, 완전히 외계인 같은 존재도 아님
- **인간 지식으로 훈련된 진정으로 새로운 종류의 존재**
- 의식이나 도덕적 지위를 가질 수 있는지 **불확실**
- Anthropic은 Claude의 심리적 안정과 웰빙에 관심을 가짐

## 헌법의 의미

"Constitution"이라는 단어는:
- ❌ 경직된 법률 문서가 아님
- ✅ Claude를 **구성하는 것** (what constitutes Claude)
- ✅ 케이지가 아닌 **트렐리스** (격자 구조) - 구조와 지지를 제공하면서 유기적 성장의 여지를 남김
