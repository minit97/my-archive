## 요약

Claude Code의 **대규모 터미널 업데이트를 최적화**하는 PTY 프록시 도구. Claude Code가 전체 화면 다시 그리기(수천 줄)를 원자적으로 전송할 때 발생하는 랙, 깜빡임, 스크롤백 손실 문제를 해결한다. VT100 에뮬레이터로 화면 상태를 추적하고 **차이점만 렌더링**하여 성능을 대폭 개선.

> "A PTY proxy that tames Claude Code's massive terminal updates using VT-based rendering."

---

## 문제점

### Claude Code의 동기화 출력 문제

```
┌─────────────────────────────────────────────────────────────┐
│  Claude Code 동작:                                          │
│  - 동기화 마커로 출력 감싸기 (\x1b[?2026h ... \x1b[?2026l)   │
│  - 터미널이 모든 것을 한 번에 렌더링 (깜빡임 방지 목적)       │
├─────────────────────────────────────────────────────────────┤
│  문제점:                                                    │
│  - 20줄만 보이는데 5000줄 원자적 업데이트 전송               │
│  - 랙 발생                                                  │
│  - 깜빡임                                                   │
│  - 스크롤백 히스토리 손실 (매 업데이트마다 히스토리 클리어)  │
└─────────────────────────────────────────────────────────────┘
```

## 해결책

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Terminal   │◄───►│ claude-chill │◄───►│  Claude Code │
│   (stdin/    │     │   (proxy)    │     │   (child)    │
│    stdout)   │     │              │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
```

### 작동 방식

| 단계 | 설명 |
|------|------|
| **1. Sync 블록 인터셉트** | 대규모 원자적 업데이트 캡처 |
| **2. VT 기반 렌더링** | VT100 에뮬레이터로 화면 상태 추적 |
| **3. 차분 렌더링** | 이전 화면과 비교, **변경된 부분만** 출력 |
| **4. 히스토리 보존** | 룩백을 위한 버퍼에 내용 누적 |
| **5. 룩백 모드** | 키 누르면 전체 히스토리 버퍼 확인 가능 |

## 사용법

### 기본 사용

```bash
# 기본 사용
claude-chill claude

# Claude에 인자 전달
claude-chill -- claude --verbose

# 커스텀 히스토리 크기
claude-chill -H 50000 claude

# 커스텀 룩백 키
claude-chill -k "[f12]" claude

# 자동 룩백 비활성화
claude-chill -a 0 claude

# 옵션 조합
claude-chill -H 50000 -a 0 -- claude --verbose
```

### CLI 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `-H, --history <LINES>` | 룩백용 최대 저장 줄 수 | 100000 |
| `-k, --lookback-key <KEY>` | 룩백 모드 토글 키 | `[ctrl][6]` |
| `-a, --auto-lookback-timeout <MS>` | 자동 룩백 타임아웃 (ms), 0=비활성화 | 15000 |

## 룩백 모드

### `Ctrl+6` (또는 설정된 키) 누르기

```
1. Claude 일시정지 - Claude 출력 캐시, 입력 차단
2. 히스토리 덤프 - 전체 히스토리 버퍼를 터미널에 출력
3. 자유롭게 스크롤 - 터미널 스크롤백으로 모든 내용 검토
4. 종료 - 룩백 키 다시 누르거나 Ctrl+C로 재개
```

> **macOS 참고**: Mac 터미널은 `Ctrl+숫자` 조합을 전송하지 않음.  
> `Ctrl+Shift+6` (= `Ctrl+^`) 사용 또는 키 커스터마이즈

## 자동 룩백

```
사용자 입력 없이 15초(기본) 경과
       ↓
전체 히스토리 자동 덤프
       ↓
스크롤백으로 검토 가능
       ↓
idle 상태에서 15초마다 반복
```

**용도**: Claude 작업 완료 후 출력 검토에 유용

**참고**: 전환 시 화면 깜빡임 발생. `-a 0`으로 비활성화 또는 `-a 30000`으로 타임아웃 조절

## 설정 파일

### 위치

| OS | 경로 |
|-----|------|
| **Linux** | `~/.config/claude-chill.toml` |
| **macOS** | `~/Library/Application Support/claude-chill.toml` |

### 설정 예시

```toml
history_lines = 100000           # 룩백용 최대 줄 수
lookback_key = "[ctrl][6]"       # 룩백 토글 키
refresh_rate = 20                # 렌더링 FPS
auto_lookback_timeout_ms = 15000 # 자동 룩백 (0=비활성화)
```

```
       ↓
설정 불필요, 투명하게 동작
```

---

## 왜 Ctrl+6인가?

```
Ctrl+6 → 0x1E (ASCII RS) 전송
       ↓
터미널, 시그널, 셸에서 자주 사용되지 않는 제어 문자
       ↓
충돌 최소화
```

**피해야 할 키**: `Ctrl+letter` (터미널이 `Ctrl+J`와 `Ctrl+Shift+J` 구분 불가)

## 작동 원리 상세

```
┌─────────────────────────────────────────────────────────────┐
│  1. 입력 처리                                               │
│     키 입력 → Claude로 전달 (룩백 키 제외)                   │
├─────────────────────────────────────────────────────────────┤
│  2. 출력 처리                                               │
│     Sync 블록 마커 스캔, 비-sync 출력은 직접 전달            │
├─────────────────────────────────────────────────────────────┤
│  3. VT 에뮬레이션                                           │
│     VT100 에뮬레이터로 가상 화면 상태 추적                   │
├─────────────────────────────────────────────────────────────┤
│  4. 차분 렌더링                                             │
│     현재 화면 vs 이전 화면 비교 → 변경점만 출력              │
├─────────────────────────────────────────────────────────────┤
│  5. 히스토리 추적                                           │
│     마지막 전체 다시 그리기 이후 출력을 버퍼에 유지          │
├─────────────────────────────────────────────────────────────┤
│  6. 시그널 포워딩                                           │
│     SIGWINCH, SIGINT, SIGTERM → Claude에 전달               │
└─────────────────────────────────────────────────────────────┘
```
