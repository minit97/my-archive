## 요약

Cursor 2.4는 **복잡한 장기 실행 태스크**를 해결하기 위한 에이전트 하네스 개선을 도입한 메이저 릴리스. **Subagents** (병렬 실행 전문 에이전트), **Skills** (도메인별 지식/워크플로우), **Image Generation** (이미지 생성) 기능이 추가되었으며, 29개 개선사항과 14개 버그 수정 포함.

> "Agents are solving increasingly complex, long-running tasks across your codebase."

## 주요 신기능

### 1. 🤖 Subagents

```
┌─────────────────────────────────────────────────────────────┐
│  Parent Agent                                               │
│       │                                                     │
│       ├──→ Subagent 1 (코드베이스 리서치) ──┐              │
│       │                                      │              │
│       ├──→ Subagent 2 (터미널 명령 실행)  ──┼──→ 결과 통합 │
│       │                                      │              │
│       └──→ Subagent 3 (병렬 작업 스트림) ──┘              │
└─────────────────────────────────────────────────────────────┘
```

| 특징 | 설명 |
|------|------|
| **독립적 에이전트** | 부모 에이전트의 개별 태스크 전담 |
| **병렬 실행** | 동시에 여러 서브에이전트 실행 |
| **독립 컨텍스트** | 각자 고유 컨텍스트 사용 |
| **커스텀 설정** | 프롬프트, 도구 접근, 모델 개별 설정 가능 |

#### 기본 제공 서브에이전트

| 서브에이전트 | 용도 |
|--------------|------|
| **Codebase Researcher** | 코드베이스 조사 |
| **Terminal Runner** | 터미널 명령 실행 |
| **Parallel Worker** | 병렬 작업 스트림 처리 |

#### 장점

- ⚡ **더 빠른 전체 실행**
- 🎯 **메인 대화의 포커스된 컨텍스트**
- 🔬 **각 하위 작업에 전문화된 전문성**

> 커스텀 서브에이전트 정의 가능 - [문서](https://cursor.com/docs) 참조

### 2. 📚 Skills

```yaml
# SKILL.md 예시
---
name: my-skill
description: 스킬 설명
---

# 커스텀 명령, 스크립트, 지침 포함
```

| 특징 | 설명 |
|------|------|
| **동적 발견** | 에이전트가 관련 스킬 자동 발견/적용 |
| **슬래시 명령** | `/` 메뉴로 직접 호출 가능 |
| **SKILL.md 파일** | 커스텀 명령, 스크립트, 지침 정의 |

#### Rules vs Skills 비교

| 항목 | Rules | Skills |
|------|-------|--------|
| **적용 방식** | 항상 켜짐 (Always-on) | 동적 발견 |
| **용도** | 선언적 규칙 | 절차적 "how-to" 지침 |
| **컨텍스트** | 항상 로드 | 필요시만 로드 |
| **유연성** | 낮음 | 높음 |

> Skills는 도메인별 지식과 워크플로우가 관련될 때 더 효과적

### 3. 🎨 Image Generation

```
텍스트 설명 또는 참조 이미지 업로드
           ↓
    Google Nano Banana Pro 모델
           ↓
    인라인 프리뷰 + assets/ 폴더 저장
```

| 용도 | 예시 |
|------|------|
| **UI 목업** | 와이어프레임, 컴포넌트 디자인 |
| **프로덕트 에셋** | 아이콘, 일러스트레이션 |
| **아키텍처 다이어그램** | 시스템 구조 시각화 |

---

### 4. 🔍 Cursor Blame (Enterprise)

```
기존 git blame + AI 어트리뷰션 확장
           ↓
   AI 생성 vs 인간 작성 코드 구분
           ↓
   생성한 대화 요약 및 컨텍스트 연결
```

| 구분 | 추적 대상 |
|------|-----------|
| **Tab 완성** | 자동 완성 코드 |
| **에이전트 실행** | 모델별 분류 |
| **인간 수정** | 사람이 직접 작성 |

#### 활용

- 코드 리뷰/재방문 시 AI 생성 부분 확인
- 변경 이유와 컨텍스트 파악
- 팀 전체 AI 사용 패턴 추적

---

### 5. ❓ Clarification Questions from Agent

```
에이전트가 명확화 질문 요청
           ↓
   사용자 응답 대기 중에도 작업 계속
   (파일 읽기, 편집, 명령 실행)
           ↓
   응답 도착 시 즉시 반영
```

#### 사용 방법

- **Plan 모드**: 계획 수립 시 질문
- **Debug 모드**: 디버깅 중 질문
- **일반 대화**: 모든 대화에서 가능

> 커스텀 서브에이전트/스킬에서 "use the ask question tool" 지시로 활용 가능

## 기능 비교: Subagents vs Skills

| 항목 | Subagents | Skills |
|------|-----------|--------|
| **목적** | 태스크 분업 (누가) | 워크플로우 정의 (무엇을) |
| **실행** | 병렬 실행 | 순차적 적용 |
| **컨텍스트** | 독립 컨텍스트 | 메인 컨텍스트 공유 |

## 핵심 포인트

1. **Subagents 도입**: 병렬 실행, 독립 컨텍스트, 전문화된 태스크 분업
2. **Skills 지원**: `SKILL.md` 파일로 도메인별 워크플로우 정의, Rules보다 유연
3. **Image Generation**: Google Nano Banana Pro 모델로 UI 목업, 다이어그램 생성
4. **Cursor Blame**: Enterprise 전용 AI 어트리뷰션 추적
5. **비동기 질문**: 에이전트가 질문하면서도 작업 계속 진행 가능
6. **생태계 통합**: Claude Code, Codex, Gemini CLI와 스킬 포맷 호환 추세
